# Cantale — Site web (Next.js)

Refonte du site Cantale en **Next.js (App Router)**.

## Développement

```bash
npm install
npm run dev
```

Copier `.env.example` vers `.env.local` et renseigner les variables nécessaires.

## Déploiement

Prévu pour Vercel (root = ce dépôt). Build : `npm run build`.
