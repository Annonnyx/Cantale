LES RÈGLES

Le non-respect de ces règles entraîne des sanctions allant du mute au bannissement définitif. Aucune exception.

01 Règles Générales
  • Respectez tous les joueurs. Insultes, harcèlement, racisme, homophobie ou tout comportement toxique = sanction immédiate.
  • Pas de triche. Les clients modifiés (x-ray, fly hack, kill aura, etc.) sont interdits. Utilisation = bannissement permanent.
  • Pas d'exploitation de bugs. Si vous trouvez un bug, signalez-le. L'exploiter = sanction. Les dupes sont particulièrement visés.
  • Pas de spam ni flood. Le chat doit rester lisible. Publicité pour d'autres serveurs = bannissement.
  • Langue française. Le serveur est francophone. Le français est exigé dans le chat public.
02 Gameplay & Vies
  • 3 vies, pas plus. Chaque mort retire une vie. À 0 vie = bannissement automatique. Les admins ne redonnent pas de vies sauf circonstances exceptionnelles.
  • Le PvP est ouvert. N'importe qui peut attaquer n'importe qui hors des zones protégées. C'est la loi de Cantale.
  • Les items custom ne sont pas craftables. Ils s'obtiennent uniquement via l'hôtel des ventes /ah, les échanges /trade, ou les récompenses de grade.
  • La falsification d'items custom est interdite. Renommer un item pour imiter un custom item = sanction.
  • Le système /wanted est légal. Mettre une prime sur quelqu'un fait partie du jeu. Les chasses à l'homme sont encouragées.
03 Factions & Territoire
  • Les noms de faction doivent être appropriés. Pas de noms offensants, racistes ou à connotation illégale.
  • Les claims sont définitifs sauf conquête. Utilisez /f claim pour revendiquer. Unclaim est possible uniquement par les officiers.
  • Le mode PASDIC protège les chunks critiques. Il nécessite un vote de la faction. Voir /pasdic.
  • Les banques de faction sont gérées par les officiers. Le retrait est soumis aux permissions du grade. Voir /f bank.
  • Le mode secret dure 24h. Cooldown de 24h entre chaque activation. Voir /f secret.
04 Économie & Échanges
  • Les Cantox sont la monnaie officielle. Utilisez /pay pour payer, /balance pour voir votre solde.
  • L'hôtel des ventes est régulé. Pas de listings abusifs ou trompeurs. Les admins se réservent le droit de retirer des annonces.
  • Les arnaques sont interdites. Tromper un joueur lors d'un échange /trade = sanction.
  • Pas de commerce IRL. Vendre des items ou des Cantox contre de l'argent réel en dehors de la boutique officielle = bannissement.
05 Grades Premium
  • 3 grades premium : Aventurier, VIP, Chèvre. Chaque grade inclut les avantages du grade inférieur. Consulte la boutique pour les détails.
  • Les avantages de grade sont personnels. Partager un coffre privé ou prêter un Statio-Lytra est toléré, mais l'abus sera sanctionné.
  • Le bonus Cantox est limité à 1× par jour. Se reconnecter ne donne pas de bonus supplémentaire.
  • Les Vies mensuelles sont des items consommables. 1/mois (Aventurier), 2/mois (VIP), 3/mois (Chèvre). Tu peux les stocker et les utiliser quand tu veux.
  • Le vol créatif (Chèvre) ne fonctionne que dans les claims de votre faction. Hors claims = chute.
  • Les items des coffres privés sont conservés 30 jours après l'expiration du grade. Au-delà, ils sont supprimés.
06 Modération
  • Les décisions du staff sont finales. Les contestations se font via Discord, pas en jeu.
  • Les sanctions sont progressives : Avertissement → Mute → Kick → Bannissement temporaire → Bannissement permanent.
  • Le bannissement à 0 vie est automatique. Ce n'est pas une sanction du staff, c'est le système de vies hardcore.
  • Les signalements se font via /moderation ou sur le Discord. Fournissez des preuves (screenshots, vidéo).
⚠ Avertissement
Ces règles peuvent évoluer. Tout changement est annoncé sur le Discord. L'ignorance des règles n'est pas une excuse. En jouant sur Cantale, vous acceptez ce règlement dans son intégralité.
