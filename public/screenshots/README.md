# Captures — galerie d’accueil

Déposer ici des images `png`, `jpg`/`jpeg` ou `webp`. Elles apparaissent automatiquement sur la page d’accueil (section « Cantale en images », lightbox). Tant que le dossier est vide, la section n’est pas rendue.

Noms de fichiers lisibles (ex. `spawn-forge.png`) : le libellé alt est dérivé du nom. Pas d’images inventées — uniquement de vraies captures du serveur.
